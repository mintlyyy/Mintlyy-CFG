## 📌 Requirements & Recommendations

To get the best experience with this config, make sure to check out:

* ⚙️ **[mastercomfig](https://mastercomfig.com/)** - Don't forget to install mastercomfig!

## 🛠️ How to Install

1. Click on the green **Code** button at the top and click **Download ZIP**.
2. Extract the files.
3. Put the `cfg` files inside your TF2 folder:
   `Steam\steamapps\common\Team Fortress 2\tf\custom\mintlyy-cfg\cfg`
4. Open the game and enjoy!

### Por que isso fica legal no GitHub?
1. **Destaque:** As pessoas já batem o olho e sabem que é uma config focada em **Spy**.
2. **Links:** Se alguém não conhecer o Mastercomfig, o texto vira um link clicável direto para o site oficial.
3. **Instruções:** Quem baixar já sabe exatamente onde colar os arquivos.

Se a sua config de Spy tiver algum script legal (tipo botão para esconder a faca/arma, ou atalho de disfarce), você me avisa que podemos adicionar uma seção explicando as teclas!
